## 🧪 How I Approach Engineering Problems

```text
Understand the Specification
            ↓
       Define the Test
            ↓
     Stimulate the DUT
            ↓
      Observe Behavior
            ↓
      Collect Evidence
            ↓
       Analyze Failure
            ↓
       Find Root Cause
            ↓
          Fix
            ↓
        Regression
            ↓
       Document
```

I care about more than a PASS/FAIL result. The goal is to understand **why** a system behaves the way it does and to leave behind enough evidence for someone else to reproduce the result.
