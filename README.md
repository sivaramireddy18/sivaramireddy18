## 🧪 My Validation Method

```text
Understand the Specification
            ↓
       Define the Test
            ↓
      Stimulate the DUT
            ↓
       Observe Behavior
            ↓
      Collect Evidence
            ↓
       Isolate Failure
            ↓
       Find Root Cause
            ↓
           Fix
            ↓
        Regression
            ↓
        Document
```

I focus on **reproducible evidence and root-cause analysis**, not just PASS/FAIL. The objective is to understand how the CPU, firmware, peripherals and system hardware interact and to make failures repeatable and diagnosable.
